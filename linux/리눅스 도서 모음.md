## Linux 현장 작업 순서 (기술지원)
1. df : 남은 용량 파악 (디스크 파티션 구성, 데이터 배치 상황 등)
2. ps : 프로세스 확인
3. free : 메모리 사용 상황 확인
4. 환경변수 확인
5. 디버깅 시작

## 명령어
- ll, ls, ls-ltr, pwd
- tab : 명령어 자동생성
- .. : 뒤로가기
- shift + insert : 복붙
- tail -f 로그 파일 : 실시간으로 log에 기록되는 것들 출력
### vi 내에서
- set nu : 번호 생성 (1, 2, 3, ...)
- shift + g : vi에서 맨 밑으로 이동
